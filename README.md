# Inchworm Tactile — リアルタイム3D実験ラボ

`run.bat` をダブルクリックで起動。専用の `.venv` にPanda3D 1.10.16とPillow 12.2.0を導入済みです。Quest 3は不要です。別PCではPython 3.12を用意して `setup.bat` を実行してください（依存ライブラリのダウンロードが必要）。

[3D実行画面](docs/visualizer-3d.png) / [比較結果](docs/benchmark-v2.json) / [元の設計依頼](docs/design-request.md)

## リアルタイム3D表示

Panda3Dの立体メッシュ、遠近投影、深度判定、照明・シャドウマップで仮想空間を描画します。3D画像を既存Tk画面に埋め込み、触覚とネットワークを同時表示します。

- 左ドラッグ：視点の回転。上下は地面より上の範囲に制限。
- ホイール：ズーム。ダブルクリック：視点リセット。
- 追従カメラOFF：その時点の注視位置を固定。ONで身体に追従。
- 一時停止中も視点操作が可能。触覚だけの表示では3D描画を停止。
- 6リンク・関節・前後パッド・頭部のセンサ面を立体化。緑の足は支持、橙は滑り、青い柱は垂直荷重。
- 餌・害・障害物は物理の円形判定に合わせて円柱で表示し、摂食した餌は消えます。

**今回の変更は描画の3D化です。物理はv2の前後2点支持モデルを維持しています。** 立体表示になっても自由な3D運動や段差登りの物理は追加されていません。身体メッシュの太さと上方10 mmの表示オフセットは観察用で、衝突判定形状ではありません。
映像・カメラはAIの入力に使わず、レンダラーはWorldを読み取るだけです。制御器・学習済みv2重み・CSV形式は互換です。

```powershell
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m unittest -v
```

18件のテストが成功（従来14件＋描画の観察専用性、カメラ変更、餌表示とリセット、ズーム制限）。3D依存未導入のPythonでは描画4件はスキップされます。
描画には利用可能なOpenGL環境が必要です。起動できない場合は `setup.bat` で依存を修復するか、`run.bat --legacy` で旧疑似3D表示を利用してください。旧表示は標準Pythonから `python app.py --legacy` でも起動できます。
実装に使用した公式資料：[画像のRAM転送](https://docs.panda3d.org/1.10/python/reference/panda3d.core.Texture)、[照明と影](https://docs.panda3d.org/1.10/python/programming/render-attributes/lighting)。

## 支持方式の実装順序

1. **directional（標準）**：前へ滑りやすく後ろへ滑りにくい受動パッド。伸長時は後足、収縮時は前足で支持。
2. **load_transfer**：前後とも等方摩擦。非対称な身体形状による荷重差で支持を切替。固定動作では曲率の前後配分を周期的に変える。
3. **active_grip（追加機構の実験）**：前後グリップの2出力を追加。足裏の摩擦係数を把持／解放で切替。有限の保持力なので完全固定ではない。

上部の「支持方式」で切替。「制御」の `reference` は3秒周期の固定動作、`ai` は5節の局所制御です。切替時はリセットし、記録中のCSVを閉じます。
まず「地面」シナリオ＋`reference`で、後足stick→前足stickの交代を確認してください。

## 表示・操作

- CG、腹側3×15＋頭部3×3の触覚、5節ネットワークを同時表示。
- 足裏の緑はstick、橙はslip。青い矢印は垂直荷重。数値欄に荷重N・接線力F・1フレームの滑り量を表示。
- 正味Xは前後パッド中点の初期位置からの変位。軌跡長は平面モデルの支持線方向の移動量の積算。旋回中の厳密な重心軌跡ではありません。
- 追従カメラをOFFにすると固定視点。固定視点では長く進むと画面外に出ます。
- Spaceで停止／再開、Tabで本体／触覚／両方を切替。
- 手動目標角で5相対ピッチ＋頭yawを操作。負のピッチで上向きのアーチを作ります。正方向など腹が地面に入る姿勢は制限されます。
- 手動グリップの2チェックは、手動目標角かつactive_gripの場合だけ使います。
- 表示ガンマ・ゲイン・縦横配置・セル間隔はAI入力に影響しません。
- 記録開始／停止で `sessions/日時.csv`。正常終了時も閉じます。

## 身体と物理モデル

**5個の駆動関節・5個のセンサ付きモジュール**に、受動的な後足側キャリアを加えた6リンク構成です。各リンク45 mm、全長270 mm。後足キャリアはセンサ数・制御チャンネルを増やしません。旧CGではPと1～5、新3Dでは6個の立体リンクとして表示します。
5ピッチは隣接リンク間の相対角です。後足側の受動ピッチと本体高さは、前後のパッドが同じ平面に接する条件から求めます。左右ロールはありません。

質量を各リンクに等分し、重力とモーメントの静的釣合いから前後パッドの垂直荷重を求めます。
静止摩擦限界は `mu * normal_load`。候補姿勢による前後間隔の変化に対し、弱い足を滑らせ、強い足を支持にします。同条件なら両足を対称に動かし、架空の前進を作りません。
動摩擦力は静止限界に `kinetic_ratio` を掛けます。駆動力は `max_drive_n` と関節トルク×角変位から得た仕事量の上限で制限します。これは個々の関節トルクを解く動力学ではなく、仕事量による近似です。
支持力不足では角度更新を止めます。空中の地面固定や無限のグリップ力は使いません。

**前後2点・平面支持に限定した準静的モデルです。** 慣性、弾性の詳細、足の離地、段差への乗り上げ、中央部の多点荷重分配、転倒、全身3D動力学は未実装です。腹が平面へ侵入する姿勢は拒否します。障害物に身体の線分が入る動作は停止しますが、接触インパルスや段差登りは解きません。
頭yawから身体の進行方向を変える部分は引き続き簡易近似です。停止状態からの旋回や確実な回避は未達です。
荷重移動方式は小さな荷重差でも支持が切り替わる理想モデルなので、摩擦ばらつき・弾性・慣性を含む実機性能を保証しません。

## AIとセンサの境界

局所制御器は各節の9輝度、頭節のみ頭部9輝度、および隣接節の4状態だけを受け取ります。位置・荷重・摩擦状態・HP・CGは入力されません。
v2では隣接節を同位相へ結合し、上向きアーチの曲げ伸ばしを生成します。触覚の接触量で局所周期速度を変えます。学習前から歩行用の周期則がある、手設計を含む小さな再帰制御器です。
active_gripの自律出力は端の局所位相と端の触覚だけで決めます。referenceは比較用の時刻ベースで、触覚学習AIではありません。

センサは15 mmピッチ、30 Hz、底輝度＋非線形飽和＋ノイズ＋1～2フレーム遅延。前後モジュールの触覚はパッド荷重を押し込みに換算した近似です。中央は高さと材質からの幾何的押し込みです。パッド内の細かな荷重分布・剪断・滑りの直接検出は未実装。
材質の硬さ・粗さは `config.json` で校正可能です。物体は円形判定・円柱CG（旧表示は角柱）。柔らかい物体の体積変形は未実装です。
パッドの摩擦係数は物体の見た目から推定せず、外部パラメータで指定します。現状、材質ごとの摩擦係数切替はしません。

## 設定・テスト・比較・学習

```powershell
python -m unittest -v
python benchmark.py --seconds 30
python train.py --generations 3 --population 6 --seconds 45 --output checkpoints/v2.json
.\.venv\Scripts\python.exe app.py --weights checkpoints/v2.json
```

`config.json` のphysicsに質量・摩擦係数・駆動力・トルク・角速度を定義。変更は再起動時に反映します。
14件のテストで支持交代、摩擦反転による後退、対称摩擦での周期後の変位ゼロ、力不足の停止、両グリップの保持、荷重釣合い、リンク長、障害物停止、センサ遅延、局所性、記録等を検証します。
`benchmark.py` は3方式×2制御×平地／標準環境を測定します。移動量は評価専用で学習器には渡しません。

学習は8共有パラメータの進化的探索で、報酬はHP時間積分だけです。標準環境の餌を、静止では届かない位置に移しました。ただし、安全な場所で静止する方が有利になる可能性は残ります。HP改善を歩行や探索の改善と解釈しないでください。
ノイズseed 7/17で探索し101/202で検証します。未知配置への汎化検証ではありません。
旧v1の重みは角度・周期則が異なるため読み込みを拒否します。v2の例は `docs/training-v2.json` です。以前の `training-example.json` と `validation.md` は旧版の履歴資料です。

## 同期ログ schema 2

1セッション1CSV。先頭の `# JSON` 行に環境・センサ・物理・重み・開始tickを保存。`pandas.read_csv(path,comment='#')` 等で読めます。
輝度54個はその行の行動決定に使った遅延済み観測。目標角6個、適用後実角6個、HP、頭部姿勢に加え、制御モード、支持方式、前後荷重・滑り・接線力・グリップ指令、後足X、軌跡長を記録します。単位はm・rad・N・秒。
物理量は評価・検証列であり、後段の触覚限定学習では観測列に混入させないでください。グリップ指令はactive_grip以外では物理に適用されません。途中記録は完全な再開スナップショットではありません。

## Unity / Questへの分担

Python版は支持方式・局所則・センサ・ログの比較検証を担当。Unity版は実関節・多点接触・剛体物理・3D CGを担当します。HMDは最後に触覚専用画面として接続します。
方向性摩擦／荷重移動は54輝度→6目標角を維持。能動グリップを実機に採用する場合のみ、前後の追加2出力を仕様として確定する必要があります。
将来のQuest操作はA:節選択＋角度、B:両手の傾きで節群、C:トリガーの収縮度を各節角へ展開。すべて目標角に正規化して記録します。別AIへの依頼文は作成していません。
