# Inchworm Tactile — 3節・2関節の未学習個体

`C:\dev\inchworm-tactile\run.bat` で起動します。3つの六角柱剛体（尾節・中節・頭節）を2関節で直列接続しました。脚・足台・独立した頭の部品はありません。全長270 mm、対辺36 mm（対角約41.6 mm）。六角柱の平らな面を下にし、全節が床に横たわる姿勢から始まり、初期中心高さは19 mmです。

## 制御と身体

各関節はXYZの3軸、合計6目標角です。Bulletが重力、慣性、接触、摩擦、有限トルクのモーターを計算します。姿勢の一括取消、起立制御、バランス反射、固定歩行パターンはありません。床に接触した部分を支点に曲がる・転がることができます。

尾節と頭節に支持機能を残しています。接触時のみ有限力のばねで掴み、支持指令0.1未満で解除、過負荷でも解除します。脚や足台を追加する機能ではありません。ネットワークのゼロ出力は支持0です。以前のsigmoidによる初期支持約0.5を廃止しました。

ネットワークも尾・中・頭の3個です。各内部状態4、隣接通信4、共有ランダム重み212個を固定します。学習OFFで、周期的な探索ノイズや起立の補助は入れていません。弱い指令で微動・停止することもあります。移動が起きても歩行学習の結果ではありません。関節モーターは指令角へ力を加える機構で、学習機構ではありません。

## 入出力と表示

入力は表面触覚27（各節3×3）、頭前面9、関節の正負受容器12（2関節×3軸×2）、支持触覚18、HP・被ダメージ・空腹・摂食回復4の計70値です。触覚はノイズと1〜2フレーム遅延を通します。画像、位置、物体種別、時刻、実角度の数値はAIに入力しません。
尾ネットワークが関節1 XYZと尾支持、頭ネットワークが関節2 XYZと頭支持を出力します。中節は感覚と隣接通信を担当します。

3D表示は3節の実姿勢、触覚グリッドは3節分、ネットワーク図も3個を表示します。手動目標角をONにすると関節1/2のXYZを個別に試せます。例えば関節1 Y=+0.6、関節2 Y=-0.6で床上から曲がることを確認できます。起動時は手動OFFです。

ドラッグで視点回転、ホイールでズーム、Spaceで停止、Tabで表示切替。配置設定で初期XY・向き、餌・害・障害物の位置・数とランダム化を変更できます。初期XYは尾端。既存の `user-layout.json` を継続使用します。

## 検証と記録

```powershell
.\.venv\Scripts\python.exe -m unittest -v
.\.venv\Scripts\python.exe observe.py --seconds 30 --output docs/three-segment-observation.json
```

CSV schema 5、controller version 5。70入力、6目標角・6実角、支持指令、接触荷重、生理状態を記録。以前の身体のログとは意味が異なります。学習更新は0回、初期重みは固定です。

初期HP100、空腹20。空腹+0.5/秒、基礎HP-0.2/秒、空腹100で追加HP-2/秒、害でHP-12/秒。頭が餌に1秒接触すると空腹を最大40回復。HP0で停止します。

障害物は衝突する剛体、餌と害は触覚・生理に作用する領域です。皮膚と関節触覚は仮想モデルです。支持グリッドは端の節の平均接触荷重を共有し、厳密な局所圧力ではありません。離散物理の小さなめり込みや数値振動があります。

## 関節可動域

各関節の上下Y・左右Zは、中立から各方向120°（−120°〜＋120°、合計240°）です。ひねりXは従来の±0.9 radを維持します。AI出力、手動スライダー、物理制限、関節触覚の正規化を統一しています。床や他の節に接触したとき、有限トルクで届かない姿勢はあります。可動域の拡大だけでAIが大きく動くことを保証するものではありません。

## 六角柱と摩擦

3D表示とBulletの凸包衝突形状は同じ24頂点を使います。接触マージンは0.5 mm。表面触覚は中央帯の底面上に配置します（長さ方向の間隔4 mm）。摩擦は全節共通で通常1.0（以前の端節0.35・中節0.6から増加）、把持最大時1.8（以前1.2）。`config.json` の `physics.mu_released` と `mu_gripped` で変更できます。床の摩擦係数は1.0です。
平面と角によって転がりにくくしますが、転倒や滑りを禁止する拘束は追加しません。摩擦を上げてもAIが大きな目標角を出すようにはなりません。学習OFF・固定歩行なし・上下左右±120°を維持しています。隣接節も衝突を有効にしています。

## 関節周辺の形状

六角断面を保ちながら両端を細く絞りました。中央の幅は従来通り、幅広部分の長さ10 mm、端部半径2 mm。端部から関節中心まで5 mm空け、直線姿勢で向かい合う端部間に10 mmの隙間があります。関節中心は小さな球で表示する観察用マーカーです。接続力は物理エンジンの関節拘束で扱います。
隣接節の衝突を有効にし、上下・左右それぞれ±120°を、隣接形状のめり込みなしで検証します。全長の基準270 mmと±120°の指令範囲は維持します。複数関節の組み合わせでは頭と尾や床に接触し、目標に届かない姿勢もあります。
