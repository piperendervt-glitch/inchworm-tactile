# Inchworm Tactile — 未学習AIと簡単な3D身体

`C:\dev\inchworm-tactile` の `run.bat` で起動します。ブランチは `feature/newborn-untrained`。学習OFF、固定歩行パターンなし、初期重みは固定です。

[実行画面](docs/rigid-visualizer.png) / [30秒の観察結果](docs/rigid-observation.json)

## 身体と物理

Panda3D同梱のBulletを使用します。胴体1個・前後脚2個の剛体と、胴体に固定した頭部です。前後脚の関節はXYZ各3軸、計6軸（目標角±0.9 rad）。Xは左右への傾き、Yは前後への振り、Zはひねりです。
足先は幅のある箱形で、脚と一体です。重力、質量・慣性、衝突、摩擦、関節拘束、有限トルクのモーターを計算します。姿勢を直接書き換えたり、床接触時に全体を巻き戻したりしません。AIは30 Hz、物理は標準240 Hzです。

支持指令0〜1は摩擦と有限保持力を調整します。0.1以上で接触点を掴み、0.1未満で離します。接触時のみ把持点を作り、ばね・減衰による力で保持します。保持力と許容変位を超えると外れます。空中に新しい支点を作れません。支持切替の順序は指定しません。

手動テストでは後脚Yを+0.8、前脚Yを-0.8にしてから両方0へ戻すと、接触を支点に胴体が上下する様子を確認できます。前後支持を1にすると把持も試せます。これは手動の身体検証で、AIへ周期や模範動作を渡すものではありません。通常の起動時は手動OFFです。

## AIとセンサ

5個の局所ネットワークは、後脚・胴体3面・前脚の触覚領域に対応します。5節の身体を意味しません。各ネットワークの内部状態は4、隣接通信も4チャネル。共有するランダム重み212個は起動後に更新しません。重みseedとセンサノイズseed、配置seedは独立です。

| 入出力 | 内容 |
|---|---|
| 表面触覚 | 後脚・胴体3面・前脚に3×3ずつ、45輝度 |
| 頭部触覚 | 胴体に固定された頭の前面3×3、9輝度。前脚側ネットワークへ入力 |
| 関節触覚 | 後XYZ・前XYZの各軸に正負受容器、12輝度 |
| 支持触覚 | 前後それぞれ3×3、18輝度。物理ソルバーの接触荷重を非線形な輝度へ変換 |
| 内的状態 | HP、直前のダメージHP低下、空腹、直前の摂食による空腹回復 |
| 出力 | 後XYZ・前XYZの6目標角＋前後の支持強度2個 |

触覚84値にノイズと1〜2フレームの遅延を加えます。関節角そのもの、位置、映像、物体種別、時刻、把持成功フラグはAIに入力しません。内部状態4値を加えた総入力は88値です。ランダムな初期重みは、毎フレームのランダム探索とは異なります。静止、微動、転倒も起こり得ます。自発探索、学習、姿勢維持の反射は追加していません。

## 表示と配置

- 3Dで剛体の実際の姿勢を表示。足は緑=把持、橙=接触、灰=空中。青い棒は接触荷重です。
- ドラッグで視点回転、ホイールでズーム、ダブルクリックで視点リセット。Spaceで停止、Tabで表示切替。
- 触覚グリッドと実際の再帰状態、前後XYZ目標・実角、支持出力、重みhashを表示します。
- 手動目標角をONにすると下部の6スライダーと前後支持を使用できます。
- 配置設定で初期XY・向き、餌・害・障害物の位置と個数、それぞれのランダム化を変更できます。初期XYは後足中心の水平位置です。
- 適用した配置は `user-layout.json` に保存。既存の配置ファイルを継続使用できます。

```powershell
run.bat
run.bat --birth-seed 17
run.bat --layout docs/layout-example.json
run.bat --legacy
```

別PCではPython 3.12で `setup.bat`。物理計算にもPanda3Dが必要です。`--legacy` はTkによる簡易表示です。ウィンドウ移動のため、Windowsメッセージ処理は引き続きTkが担当します。

## 生理状態と記録

初期HP100、空腹20。毎秒空腹+0.5、基礎HP-0.2、空腹100では追加HP-2。害への接触中はHP-12/秒。頭を餌に1秒接触させると空腹を最大40回復、餌は消えます。HP0で停止し、自動再誕生はしません。

```powershell
.\.venv\Scripts\python.exe -m unittest -v
.\.venv\Scripts\python.exe observe.py --seconds 30 --output docs/rigid-observation.json
```

CSV schema 4 / controller version 4。行動に使用した88入力、6目標角、6実角、生理状態、頭部姿勢、接触荷重、足の水平移動距離、把持力、支持指令を記録します。旧schemaとは関節・入力の意味が異なります。力は把持ばねの平均力の大きさ、荷重はソルバー接触インパルス/時間、足移動は滑りと空中運動の両方を含みます。

## 近似の範囲

障害物は衝突する剛体です。餌とダメージ床は触覚・生理状態に作用する領域で、固体障害物にはしません。皮膚の接触と関節触覚は仮想モデルで、実機校正済みではありません。足先3×3は平均接触荷重を共有し、局所圧力分布の厳密な再現ではありません。把持は有限力のばねで、爪や吸盤の詳細機構ではありません。
Bulletの離散接触には小さなめり込みと数値振動が生じます。`config.json` の質量、摩擦、トルク、保持力、サブステップを変更できます。歩行の獲得は別途学習を実装して検証する段階です。

使用API: [Panda3D BulletGenericConstraint](https://docs.panda3d.org/1.10/python/reference/panda3d.bullet.BulletGenericConstraint)
