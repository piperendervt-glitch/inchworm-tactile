# Inchworm Tactile — 生まれたばかりの未学習個体

ブランチ：`feature/newborn-untrained`。起動は `run.bat`。既存の世界・配置設定・3D表示を使い、訓練を実行せずに個体を動かします。

[実行画面](docs/newborn-visualizer.png) / [30秒の観察結果](docs/newborn-observation.json)

## このブランチの動作

固定歩行モード、周期波形、位相同期、接触で支持を交代させる手設計の制御、旧重みの読込、旧パラメータ探索スクリプトを削除しました。以前の実装はmainブランチに残っています。
支持は前後2個の独立したアクチュエータ出力で決めます。方向性摩擦による自動的な前進補助は使用しません。両足には同じ摩擦特性を使い、0〜1の支持指令で摩擦係数を連続的に変えます。

個体は共有重みの小さな再帰ネットワークです。重み192個を指定seedの乱数で初期化し、その後は固定します。内部状態は全て0で始まり、観測に応じて更新されます。内部状態の変化は学習ではありません。
学習用の損失計算・報酬最適化・重み更新はありません。重みを読み込むUIもありません。ランダム初期化されたネットワークが出す指令を、そのまま身体に適用します。歩かない、動作が収束する、物理制約で止まる場合も補正しません。
「別の新生個体」で異なる初期重みを作れます。seedを固定したリセットでは同じ個体になります。個体seed、配置seed、センサノイズseedは別のものです。

## 入力と出力

| 情報 | 実装 |
|---|---|
| 各節の触覚 | 腹側3×3×5節＝45輝度。頭部前面9輝度は頭節のみ |
| 曲げ角を感じる触覚 | 各関節に＋側・−側の仮想触覚受容器を2個、合計10輝度 |
| 支持する節の触覚 | 後・前パッド各3×3、合計18輝度。端の節だけが受け取る |
| HP | 現在HP / 100 |
| ダメージ床によるHP低下 | 直前ステップの実際のダメージ床由来HP損失 / 100 |
| 空腹 | 現在の空腹度 / 100（0で満腹、100で最大空腹） |
| 摂食による空腹回復 | 直前ステップの空腹度の回復量 / 100 |
| 曲げアクチュエータ | 各節の相対ピッチ目標角5個。頭部には従来のyaw目標角1個 |
| 支持アクチュエータ | 後・前の支持強度2個、各0〜1 |

HP等の4つの内的状態は全節に入力します。中央の行動決定器は設けず、隣接節との通信は4チャネルのままです。各節のネットワーク入力は、自節の感覚・内的状態と、自身・左右隣接節の4状態です。非搭載センサや存在しない隣接節の入力は0です。
5節は同じ重みを共有しますが、触覚・支持の有無・隣接関係が異なります。実際の支持アクチュエータは既存身体の前後2個のみで、中央節には追加していません。

**角度情報の入力は実角度の数値ではなく、曲げによる触覚輝度です。** 関節の曲げに応じて片側の受容器が押される仮想モデルで、非線形応答・ノイズ・遅延を通してから入力します。実機センサの校正済みモデルではありません。実角度は観察・記録専用です。
支持触覚も垂直荷重を押し込み量に換算して輝度化します。荷重の数値、支持成功のフラグ、ワールド位置、地図、物体の種類、CG映像、シミュレーション時刻はネットワークに渡しません。

## 生理状態

`config.json` の `physiology` で調整できます。

- 初期HP100、初期空腹20。
- 空腹は毎秒0.5増加。最大100。
- HPの基礎消費は毎秒0.2。空腹100では追加で毎秒2低下。
- ダメージ床との接触中は毎秒12のHP低下。基礎消費・飢餓と分けて記録。
- 餌へ頭部を1秒押し当てると、空腹を最大40回復し、餌を消去。
- 摂食ではHPを直接回復しません。空腹が下がることで飢餓による消耗を避けます。
- HP0で終了。学習や自動再誕生はしません。

触覚82値は30 Hzで更新し、1〜2フレーム遅延します。内的状態4値は直前ステップの値を使います。摂食・ダメージを未来から行動入力へ混ぜません。

## 画面

- 3Dで身体・環境・支持状態を表示。ドラッグで視点回転、ホイールでズーム、ダブルクリックで視点リセット。
- 触覚画面に腹側・頭部・曲げ受容器・前後支持を同時表示。
- ネットワークには4つの実際の再帰状態、目標角・実角・前後支持出力、重みhash、学習更新0回を表示。
- Spaceで停止／再開、Tabで表示切替。初期設定では未学習個体が実行中。
- 手動目標角・前後支持スライダーは身体を確認するためのテスト入力です。通常はOFF。固定歩行や模範動作は含みません。

## 配置設定

「配置設定」からAIの初期XY・向き、障害物・ダメージ床・餌の座標と個数を設定できます。位置と個数を種類ごとにランダム化し、個数範囲・配置範囲・配置seedを指定できます。
「プレビュー」→「適用してリセット」で反映。適用済み設定は `user-layout.json` に自動保存します。通常起動では保存された現在の配置を使います。
「JSON保存／読込」で配置プリセットを管理。固定座標は1行に `X,Y` または `X,Y,半径,高さ`。ランダム配置では重複を避け、配置不能ならエラーを表示します。
「地面」「餌に接触」等は物体配置のプリセットであり、行動制御ではありません。

```powershell
run.bat
run.bat --birth-seed 17
run.bat --layout docs/layout-example.json
run.bat --config config.json
```

`--config` 指定時はGUI保存配置を自動読込しません。別PCではPython 3.12を用意して `setup.bat`。OpenGLが利用できない場合は `run.bat --legacy` で従来の疑似3D描画を使えます（制御器は未学習のまま）。

## 記録と検証

```powershell
.\.venv\Scripts\python.exe -m unittest -v
.\.venv\Scripts\python.exe observe.py --seconds 30 --csv sessions/newborn.csv
```

`observe.py` は観察専用です。訓練せず、移動量・HP・空腹・物理制約・重み不変を記録します。GUI保存配置を自動読込しないため、必要なら `--layout user-layout.json` を指定してください。
CSVはschema 3です。1行に行動決定に使った82輝度＋4内的入力、出力6角度＋2支持指令、適用後の身体・生理状態を同期保存します。メタデータに初期重みとhash、個体seed、実配置、初期位置、学習OFFを記録。過去のschema 2や学習済み重みとは互換ではありません。
実角度・位置・荷重の列は観察用です。将来の学習時にこれらを入力へ混ぜないでください。

## 身体モデルの限界

身体の5相対関節・前後2点支持・静的荷重釣合い・有限摩擦・有限駆動力は維持しています。全身の3D動力学ではありません。腹が地面に入る指令、支持力不足、障害物への侵入は物理側で拒否します。正負どちらの角度指令もネットワークは出せますが、実現不能な姿勢へ自動補正しません。
支持アクチュエータは摩擦強度の近似で、実際の吸盤や爪の機構ではありません。曲げ触覚は仮想の対向受容器です。今後の実機に合わせた校正やモデル改善が必要です。
