## 餌だけの環境（GUI初期設定）

`run_ecoli.bat` は初期設定で「餌だけ」を選びます。画面の環境欄から混合環境に戻せます。新規実行時に反映します。境界の壁は残りますが、内部の障害物と危険領域は作りません。読み込んだ固定配置にそれらが含まれていても、餌だけモードでは除外します。餌が0個の設定はエラーです。

餌は初期8個をランダム配置、位置と向きもランダム化。配置seedが同じなら再現でき、個体seedを比較する間は共通配置にします。配置を変えるには配置seedを変えて新規実行してください。初期エネルギーは60で、満腹により初回の摂食が抑制されるのを避けています。設定JSONで変更できます。

画面から餌の個数と初期姿勢のランダム化を変更できます。固定objectsを読み込んだ場合はJSONの餌位置・個数が優先され、個数欄はランダム配置時のみ有効です。餌を消費するとその餌の濃度も減り、無限には補充しません。初回摂食までの時間はsummaryのfirst_food_s列に保存し、未摂食ならnull／CSV空欄です。

```powershell
.\.venv\Scripts\python.exe -m creature_sim.ecoli.trials --environment food_only --seeds 0,1,2,3,4 --seconds 60 --layout-seed 7 --output sessions/ecoli/food-trial
```

環境追加の段階であり、学習による重み更新はまだありません。学習OFFの基準結果として保存します。設定例はfood_only.json、以前の混合環境はmixed.jsonです。

# 大腸菌型・seed固定時間試行

`run_ecoli.bat` を起動すると、初期設定ではseed 0〜9を1個体ずつ60秒行動させます。画面のseed一覧・各個体の秒数・配置seedを変更して「新規実行」で再実行できます。停止/再開と実行速度1〜20倍に対応します。全個体が終了すると自動停止します。

これは大腸菌の直進／方向転換を参考にした平面モデルです。細菌の大きさや繊毛・鞭毛の詳細は再現しません。円形身体1個が抵抗を受けつつ進み、方向転換時はランダムな角度へ有限時間で旋回します。壁や障害物では進行を止め、回避方向を自動選択しません。慣性により方向転換中も少し移動します。

## 未学習の比較実験

各個体は固定されたランダムな再帰ネットワーク（内部状態4）で方向転換確率を出します。ネットワーク・行動・ノイズの乱数は個体seedから独立したストリームとして作ります。配置seedは別で、全個体に同じ配置・初期姿勢・餌量を与えて公平に比較します。学習・報酬最適化・重み更新は実装していません。摂食や回避が起きても学習済み能力ではありません。

入力は接触、現在地点の化学濃度、エネルギー/100、直前ダメージ/100、直前摂食/100、直前に方向転換していたかの6値。位置・地図・画像・餌の方向は与えません。CSVのinput列は直前観測、decision_made列がtrueの行でネットワークがその観測を使用します。回転の向きはランダムです。

## 感覚と生理

餌から指数的に減衰する濃度場を合成します。障害物による拡散の遮蔽はありません。表示の点線は濃度の広がりの目安で、正確な等濃度線ではありません。頭部と左右の濃度比較はなく、1点の濃度のみです。接触センサは衝突時1、それ以外0の簡単なモデルです。
餌は接触時だけ摂取し、有限量を減らしてエネルギーを回復します。満腹時は摂取しません。危険領域に接触するとエネルギーが減り、基礎・運動消費もあります。エネルギー0で身体は停止し、自動再誕生しません。指定された試行時間までは停止状態を記録し、death_timeで死亡を区別します。実行時間は30 Hzの最も近いフレーム数に丸めます。

## 保存と一括実行

GUIの結果は `sessions/ecoli/日時/` に自動保存。seedごとの時系列CSVと初期設定JSON、比較用summary.csv/jsonを出力します。中断時はinterrupted.jsonを残し、途中の個体を完了扱いにしません。既存の結果フォルダを上書きしません。

```powershell
.\.venv\Scripts\python.exe -m creature_sim.ecoli.trials --seeds 0,1,2,17,18 --seconds 120 --layout-seed 7 --output sessions/ecoli/run-120s
.\.venv\Scripts\python.exe -m creature_sim.ecoli.trials --config creature_sim/ecoli/config.json --seeds 0,1,2 --seconds 60 --output sessions/ecoli/custom-run
.\.venv\Scripts\python.exe -m unittest test_ecoli -v
```

`ecoli/config.json` で速度・抵抗・初期エネルギー・危険ダメージ・配置範囲・障害物/害/餌の数を変更できます。GUIは起動時に読み込み、別ファイルは「設定JSON」から読めます。`random_spawn:true` で配置seedに応じて位置と向きをランダム化。物体は設定した数を重複しない位置へランダム配置します。
固定位置を使うには `objects` に `{"kind":"food","x":0.4,"y":0.1,"radius":0.045}` のような要素を並べます。objectsがある場合、ランダム個数設定より優先します。固定障害物と初期位置が重なる場合はエラーです。

観察画面には世界・軌跡、6入力、濃度履歴、再帰状態、方向転換確率、結果一覧を表示します。各seedの摂食量、被ダメージ、移動距離、接触時間、方向転換数、残エネルギーを比較できます。既存のシャクトリムシは `run.bat` と元ブランチ `feature/newborn-untrained` に維持しています。
